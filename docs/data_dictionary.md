# ChurnGuard — Data Dictionary

## Raw Dataset: `data/raw/churnguard_customers.csv`

| Column | Type | Description | Notes |
|---|---|---|---|
| `customer_id` | string | Unique customer identifier | Synthetic ID, format `CUSTxxxxxx` |
| `age` | int | Customer age in years | Range: 18–74 |
| `tenure_months` | int | Months since account opened | Range: 1–95 |
| `num_products` | int | Number of financial products held (accounts, cards, loans, etc.) | 1–4 |
| `has_credit_card` | int (0/1) | Whether customer holds a credit card product | Binary |
| `is_active_member` | int (0/1) | Whether customer is flagged as an active member | Binary |
| `avg_balance` | float | Average account balance (currency units) | ≥ 0, right-skewed distribution |
| `monthly_transactions` | int | Average number of transactions per month | ≥ 0 |
| `support_tickets_last_90d` | int | Count of support tickets raised in the last 90 days | Poisson-distributed, mean ≈ 0.6 |
| `balance_trend_pct` | float | % change in balance over the last 90 days | Can be negative (declining balance) |
| `days_since_last_login` | int | Days since the customer last logged into the app/portal | 0–120 |
| `salary_band` | categorical | `low` / `mid` / `high` income band | Proxy for customer segment |
| `channel` | categorical | Primary engagement channel: `mobile_app` / `web` / `branch` | |
| `churned` | int (0/1) | **Target variable.** 1 = customer churned | ~31% positive class in the synthetic dataset |

## Engineered Features (added by `src/features/build_features.py`)

| Feature | Type | Description |
|---|---|---|
| `engagement_score` | float | Composite score combining transaction frequency, active-member flag, recency, and support-ticket volume. Higher = more engaged. |
| `is_inactive_recent` | int (0/1) | 1 if `days_since_last_login > 45` |
| `is_single_product` | int (0/1) | 1 if `num_products == 1` (single-product customers are typically less "sticky") |
| `is_declining_balance` | int (0/1) | 1 if `balance_trend_pct < -10` |
| `is_low_tenure` | int (0/1) | 1 if `tenure_months < 12` |
| `salary_band_*` | int (0/1) | One-hot encoded `salary_band` |
| `channel_*` | int (0/1) | One-hot encoded `channel` |

## Data Sensitivity Note

This dataset is **entirely synthetic**, generated by `generate_data.py` using
NumPy random distributions plus a hand-crafted business-logic churn signal.
No real customer data is used anywhere in this project.

**If this pipeline is adapted for a real FinTech dataset:**
- `customer_id` and any direct identifiers must be pseudonymized before
  entering this pipeline.
- `age`, `salary_band` are potentially sensitive/protected attributes —
  see `tests/test_fairness.py` for the fairness check pattern that should
  gate any production deployment using real demographic data.
- Storage and transit of real balance/transaction data must comply with
  applicable financial data regulations (e.g., GLBA, PCI-DSS scope
  assessment, GDPR if EU customers are involved).
